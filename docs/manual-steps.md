# 手动版全步骤（没有 AI 时自己照着点）

> 方法来源：零度解说视频 https://youtu.be/UG-l2OYdeqM 与博客 https://www.freedidi.com/23223.html
> 本文档是该方法的结构化整理，2026-10-25 依据原视频全程转录与博客原文核对。

## 先理解一件事：为什么 WARP 连不上

| 隧道协议 | 原理 | 问题 |
|---|---|---|
| WireGuard（默认） | 独立加密隧道协议，特征明显 | 使用广泛，容易被部分运营商屏蔽或干扰 → 卡连接、报错、慢 |
| MASQUE（要切换的） | 伪装成标准 HTTPS 加密流量（FIPS 140-2 密码套件），为受限网络设计 | 难以与正常网页流量区分 → 连得上；原作者实测比 WireGuard 快将近 1 倍 |

裸装的个人版 WARP 改不了协议。只有把设备注册进**你自己的 Zero Trust 团队**（免费），才能在后台改设备配置文件的隧道协议。

## 准备

- 一个邮箱（或 Google / Apple 账号）
- 一台电脑（Windows / macOS / Linux），手机可选
- 关掉电脑上其他所有 VPN / 代理（包括旧 WireGuard 客户端）

## 步骤

1. **注册 Cloudflare 免费账号**：邮箱 / Google / Apple 均可。登录后问卷选「个人使用」，其余跳过。界面语言可在头像菜单 → Language 切中文。
2. **开通 Zero Trust**：左侧进入 Zero Trust → 开始使用 → 设置**团队名称**（全网唯一，被占用就换；记牢完整域名 `<团队名>.cloudflareaccess.com`）。
3. **选免费套餐**（0 元，50 个席位）。到付款方式页面时点**「取消并退出 / 确定并退出」**，不填任何支付信息，功能照常可用。
4. **找到设备注册入口**：Zero Trust → 集成（或设置）→ 服务提供商 → **「使用 WARP 注册您的设备」** → 添加设备，进入官方配置向导。
5. **下载安装 WARP 客户端**：按系统选最新稳定版（Windows 版约 130MB），安装完成。
6. **向导剩余步骤**：注册策略用默认（允许你的登录邮箱注册设备）→ 服务模式选第一个**「流量 + DNS 双重代理模式」** → 默认路由选**「排除模式」** → 拆分隧道保持默认 → 完成。
7. **先改协议，再连接**：回 Zero Trust 后台 → 团队和资源 → 设备 → **设备配置文件**页签 → 找到你的设备实际命中的那份配置文件（列表按优先级排序，先命中先生效）→ 右侧「⋯」→ 配置 → 拉到最底部**「设备隧道协议」** → WireGuard 改选 **MASQUE** → 确认 → 拉到页面底部点**「保存配置文件」**。
8. **客户端登录团队**：打开 WARP 客户端 → 设置（齿轮）→ 首选项 → 账户 → **「使用 Cloudflare Zero Trust 登录」** → 输入团队名称 → 输入注册邮箱 → 填邮箱收到的验证码（发件人 Cloudflare，10 分钟内有效）。
9. **连接与验收**：点「连接」，状态变为已连接后，打开 https://www.cloudflare.com/cdn-cgi/trace ，确认 `warp` 不是 `off`，并看 `colo`（出口数据中心）；再跑一次测速、打开一个 4K 视频实测。
10. **手机端**：安装 Cloudflare One Agent（官方现行 Zero Trust 专用客户端；视频演示用的是旧版 1.1.1.1 App，其手机端 Zero Trust 支持已被官方终止）→ 右上角三横杠菜单 → 账户 → 使用 Cloudflare Zero Trust 登录 → 同一个团队名 + 邮箱验证码登录。**注意**：按原作者博客提醒，手机端需在后台**另建一份隧道协议为 WireGuard 的设备配置文件**供手机命中，桌面端继续用 MASQUE。

## 老账号

已经开通过 Zero Trust 的老账号不用重注册：直接对现有团队里设备命中的配置文件执行第 7 步的协议切换即可（原作者明确说明同样有效）。

## 界面改版怎么办

Cloudflare 后台菜单名称会随版本变化。按功能词找：**服务提供商 / 使用 WARP 注册您的设备 / 设备配置文件 / 设备隧道协议**，词对上就是它。
